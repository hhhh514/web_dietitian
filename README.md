## Node.js
### 安裝 Node.js

請從 [Node.js 官方網站](https://nodejs.org/) 下載並安裝最新版本的 Node.js。

### 安裝所需的 Node.js 套件

```sh
npm install
```
### 執行

```sh
npm run serve
```
## Python
### 安裝所需的 Python 套件

```sh
pip install numpy tensorflow flask flask-cors scikit-learn pymysql
```
### 執行 app.py

```sh
python app.py
```
